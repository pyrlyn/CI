11.1. When You open a pull request in a Project, an automated check (CLA Assistant Lite) asks every
committer who has not yet signed to accept this Agreement. You accept it by posting the following

> I have read the CLA Document and I hereby sign the CLA

your signature and stored in a repository controlled by the Licensor: your GitHub user name and
numeric user ID, the ID and timestamp of the comment, and the repository and pull request in which
You signed. The pull request comment itself remains public on GitHub.

11.3. One signature covers all your past and future Contributions to all Projects, until You notify
the Licensor in writing that it no longer applies to future Contributions. Such notice does not
